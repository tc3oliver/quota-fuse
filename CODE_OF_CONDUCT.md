# Code of Conduct

QuotaFuse contributors, maintainers, and users must provide a respectful, harassment-free environment. These rules apply to issues, pull requests, code review, discussions, and other project spaces.

## Expected behavior

- Engage constructively and assume good intent while evaluating evidence.
- Critique technical claims and security implications, not personal identities.
- Make room for different skill levels and backgrounds.
- Disclose potential billing-risk regressions responsibly and with reproducible mock tests.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, publishing someone else's private information, coercion, and intentional disruption are not tolerated. Never share live tokens or private prompts in reports.

## Enforcement

Maintainers may edit or remove inappropriate posts, close discussions, warn contributors, or restrict participation. Decisions should be proportional to the behavior, applied consistently, and may be reviewed on request. For urgent safety concerns, use a private channel listed in [SECURITY.md](SECURITY.md), if available, rather than posting identifying details publicly.
